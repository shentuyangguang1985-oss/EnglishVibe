📚 EnglishVibe PWA 图标生成器

点击下方按钮下载所需的 PNG 图标文件，然后放入 assets/icons/ 文件夹。

📱 安装到安卓手机的步骤：

  1. 点击上方按钮下载所有图标文件
  2. 将下载的 PNG 文件放入 assets/icons/ 文件夹
  3. 使用本地服务器运行项目：
    • 方式1：npx serve . （需要Node.js）
    • 方式2：python -m http.server 8080
    • 方式3：使用 VS Code 的 Live Server 插件
  4. 在安卓手机的 Chrome 浏览器中访问：http://电脑IP:端口
  5. 点击 Chrome 菜单（右上角三个点）→ "添加到主屏幕" 或 "安装应用"
  6. 完成！现在可以像普通 APP 一样使用了 🎉

🌐 部署到云端（推荐）：

  1. 注册 Vercel 或 GitHub Pages 账号
  2. 将项目上传到 GitHub
  3. 在 Vercel 中导入项目，自动获得 HTTPS 链接
  4. 在手机浏览器访问该链接，即可安装为 PWA
